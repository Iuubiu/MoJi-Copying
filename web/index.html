01导入文本

支持 .txt / .md，自动识别 UTF-8 / GBK / UTF-16 编码，并识别“第一章”“Chapter 1”等章节标题。每段会自动补上首行缩进。

02对照抄写

左侧黑色原文作为参照，右侧输入会逐字校对。开启「标点宽松」后，全角/半角与中英文引号的差异不再算错字。按回车会自动带入原文下一行的缩进。

03校对与检索

「校对清单」列出每一处偏差，点击即可跳到那个字；工具栏下方显示当前所在句；章节目录支持全文搜索与逐章重置。

04记录与备份

练习时长与字数每 5 秒自动存入本地数据库，切章节、切标签页、关窗口时自动结算，下次打开接着来。设置里可以导出/导入 JSON 备份。
