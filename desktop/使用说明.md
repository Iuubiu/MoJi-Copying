# 墨迹 · 小说抄写工作台

一个专注小说抄写与逐字校对的桌面应用。**免安装**：解压后双击 `MoJi\MoJi.exe` 就能用 ——
不需要浏览器，也不用装 Python。

（`MoJi` 文件夹里的 `_internal` 是程序的依赖，别删；要挪地方的话，整个 `MoJi` 文件夹一起挪。）

## 使用

1. 双击 `MoJi\MoJi.exe`。
2. 点击左侧「导入新小说」，选择 `.txt` / `.md` / `.text` 文件。
3. 在工作台选择章节，点「开始抄写」或直接在右侧输入。
4. 关掉窗口即可，进度会自动保存。

## 数据存在哪

书架、章节和抄写进度保存在你自己的电脑上：

```
%LOCALAPPDATA%\MoJi\moji.sqlite3
```

- 这是一个 SQLite 数据库文件，由随程序一起启动的**本地后端服务**读写，**不联网、不上传**。
- 窗口位置和大小记在同一个目录的 `config.json` 里，下次打开还是原样。
- 想备份就用设置里的「导出备份」（JSON）；想彻底清空？直接删掉上面这个文件夹即可。
- 桌面版与命令行版本（在项目根目录跑 `python -m server`）默认用**同一个数据库**：
  同一份书架，不会各写各的。

## 功能

- 导入 `.txt` / `.md` / `.text`，自动识别 UTF-8、UTF-16、GB18030/GBK 编码，并识别「第 X 章」「序章」「Chapter 1」等标题拆分章节；识别不准时可在左侧「TXT 编码」手动切换。
- 左侧黑色原文 + 右侧逐字校对抄写区：正确字黑色，错误字红色。
- **两栏逐行对齐**（同宽、同起点、同行数）；写到最后一行立即整行下滚；**抄写端最底端常年空出一行**，方便对照另一侧的原文。
- 在原文换行处按回车会自动带入下一行的空格 / 全角空格 / 制表符缩进；在行首缩进处按退格会一次移除换行与缩进占位。
- 字号调整、护眼色、专注模式；文字可选中反色。
- 自动统计完成度、已抄字数、练习时长、平均速度；章节目录与最近 7 天统计。
- 快捷键：`Tab` 切换下一章，`Ctrl/Cmd + Enter` 完成本章，`Esc` 退出专注模式。

## 常见问题

**打不开 / 提示缺少 WebView2？**
本应用使用 Windows 自带的 Microsoft Edge WebView2 内核（Win10 1803 以上通常已预装）。
若提示缺失，装一下即可：https://developer.microsoft.com/microsoft-edge/webview2/

**同时开两个会怎样？**
应用是单实例的：已经开着的时候再点一次，只会提示「已经在运行了」，不会再开一个窗口。

**和命令行 / 网页版有什么关系？**
现在是前后端分离的一套应用：`web/` 是前端（原生 HTML/JS），`server/` 是后端（Python + SQLite）。
桌面版只是把两者装进一个独立窗口，因此不依赖浏览器、不会被标签页和地址栏打断；
在项目根目录跑 `python -m server --open`，得到的是同一个界面。

## 排错

如果启动异常，可以在命令行（或 PowerShell）里跑自查，结果会打印出来并写到
`%LOCALAPPDATA%\MoJi\` 下的 `selftest.json`、`selftest-gui.json`：

```
MoJi.exe --selftest        # 只检查本地服务与前端资源是否齐全
MoJi.exe --selftest-gui    # 真开一个窗口，检查页面是否真的跑起来了
```

`--selftest-gui` 会**自动重开窗口重试**（最多 6 次），这是有意为之：
这台机器上 WebView2 把"页面 → 本机服务"的上报通道搞得时好时坏，
一整轮收不到任何上报的情况确实存在，但重开一次就好了。
所以报告里会带 `attempts` 字段，写明每一轮的结果，不会把不确定性藏起来。

报告里少数几项标了 `"optional": true`：那是"这次没看到"而不是"确实坏了"
（例如上报通道整轮没送达时，就没法确认用的是哪个存储后端）。
真正算数的门禁项都不带这个标记 —— 页面要是真出问题，每一轮都会红。
